
# CodeAlpha Python Internship

This repository contains my completed Python programming tasks for the CodeAlpha Internship.

## Tasks Completed

### Task 1: Hangman Game

A simple text-based Hangman game where the player guesses a word one letter at a time.

#### Features
- 5 predefined words
- Random word selection
- Maximum 6 incorrect guesses
- Console-based input/output

#### Concepts Used
- Lists
- Strings
- `random`
- `while` loop
- `if-else`

### Task 2: Stock Portfolio Tracker

A simple stock portfolio tracker that calculates the total investment based on stock prices and quantities entered by the user.

#### Features
- Manually defined stock prices
- User enters stock symbol and quantity
- Calculates total investment
- Saves the result to a text file

#### Concepts Used
- Dictionary
- User input/output
- Basic arithmetic
- File handling

## Technologies Used

- Python 3
